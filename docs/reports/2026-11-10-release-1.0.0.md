# 1.0.0 の公開記録

2026-11-10 に、v1.0.0 の GitHub のリリースを公開し、配信プラグイン倉庫くんに掲載しました。OBS Forums には掲載しません。

## GitHub のリポジトリ

- URL: https://github.com/AllegroMoltoV/obs-simple-burst-lines
- 既存の 3 本と同じく、GitHub の既定の設定で公開のリポジトリとして作りました。説明文とトピックは空です。GitHub はライセンスを GPL-2.0 と検出しています。
- ruleset `main` (26911772) を、drop-shadow の 11550302 と同じ内容で作りました。`id`・`source`・`node_id`・`created_at`・`updated_at`・`_links` を除いた JSON が一致することを `diff` で確認しました。
- 初回の push の CI では、macOS と Ubuntu のビルドと書式の検査が終了コード 126 で失敗しました。drop-shadow から複製したとき、Windows で実行ビット 5 件とシンボリックリンク 3 件が失われていました。PR #1 でモードとリンクを流用元と同じに戻しました。
- PR #1 から #3 のマージでは、ruleset を一時的に無効にし、マージ後に戻しました。毎回、`updated_at` と `_links` を除いた JSON が変更前と一致することを `diff` で確認しました。
