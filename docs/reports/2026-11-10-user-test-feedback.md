# ユーザーテストのフィードバック

## はじめに

初版の範囲を実装した版を、依頼者が OBS Studio 33.0.1 で試した記録です。フィードバックは受け取った順に 1 件ずつ記録し、収集の間は対応しません。収集が終わったら、依存関係を踏まえて対応の優先度と順番を設計します。計画の正本は Beads の課題 `obs-simple-burst-lines-994` です。

## 検証環境

| 項目 | 値 |
| --- | --- |
| OBS Studio | 33.0.1 (Windows) |
| プラグイン | simple-burst-lines 0.1.0。`C:\ProgramData\obs-studio\plugins\simple-burst-lines\` に導入 |
| ビルドの元 | main のローカルのコミット。ctest の D3D11 と OpenGL のスモークテストに合格 |

## 試す手順

試す手順は次のとおりです。順番どおりでなくてもかまいません。

1. 導入: ソースの一覧の「+」から「シンプル集中線」を追加します。一覧に無い場合は、ヘルプ → ログファイル → 現在のログファイルを表示 で `simple-burst-lines` を含む行を探します。
2. 見た目: プロパティの各項目を動かし、見た目の好みと、範囲と既定値の過不足を確かめます。
3. 動き: 1 秒あたりの描き替えを変え、動きの印象を確かめます。0 で止まり、60 で毎フレームの描き替えになります。線の伸縮と回転の要否も、この動きを見て判断します。
4. 表示と非表示の切替え: 設定 → ホットキー で、シーン名の見出しの下にある、追加したソースの表示と非表示の項目にキーを割り当てます。ソースを右クリック → 表示トランジション・非表示トランジション に「フェード」を設定し、ホットキーで切り替えたときの見え方を確かめます。
5. 配信の画面: ゲームやカメラの映像の上に重ね、配信で使うときの見え方を確かめます。

## 設定項目と既定値

既定値は、作者が参考の作例の見た目に近いものとして選んだ仮の値です。

| 項目 | 既定値 | 範囲 | 内容 |
| --- | --- | --- | --- |
| キャンバスの大きさに合わせる | オン | オン・オフ | オフにすると幅と高さを指定できる |
| 中心の位置 X・Y | 50% | 0% から 100% | ソースの幅と高さに対する割合 |
| 線の本数 | 120 | 8 から 400 | 一周あたりの線の数 |
| 間隔のばらつき | 100% | 0% から 100% | 0% で等間隔に並ぶ |
| 線の太さ | 30% | 1% から 100% | 線 1 本が受け持つ角度の幅に対する割合 |
| 先細りの長さ | 20% | 0% から 100% | 内側の端から線が最大の太さになるまでの長さ |
| 中心の空白の大きさ | 45% | 0% から 100% | 長さの割合は、すべて画面の対角線の半分に対する割合 |
| 中心の空白の縦横比 | 1.78 | 0.25 から 4 | 1 で円、1 より大きいと横長の楕円 |
| 中心の空白の縁のぼかし | 5% | 0% から 50% | 空白の縁で線を徐々に消す幅 |
| 長さのばらつき | 15% | 0% から 100% | 線ごとの内側の端のばらつき |
| 線の色 | 不透明の黒 | 色と不透明度 | |
| 1 秒あたりの描き替え | 12 | 0 から 60 | 線の配置を描き替える頻度 |
| 乱数のシード | 0 | 0 から 9,999 | 線の配置の乱数の種 |
